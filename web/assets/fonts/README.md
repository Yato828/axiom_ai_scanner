# Editorial font

Adelphe Floreal, retained from the scene supplied by the project owner.
Original resource: https://assets.unicorn.studio/fonts/studio_picks/Adelphe%20Floreal/remix_Adelphe-FlorealRegular.otf

`adelphe-font.js` loads the original bytes through FontFace without changing the
server's static file allowlist or Content Security Policy. The font does not
depend on the former animation runtime.
